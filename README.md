# IFC.On-Track plugins

Open-source plugins by [On-Track](https://www.on-track.nl) that bring
[bSDD](https://search.bsdd.buildingsmart.org/) classification and IDS-based information
standards into BIM tools.

| Plugin | Host | Status |
|---|---|---|
| bSDD Classification + IFC export | Revit 2025 / 2026 | Released (installers under Releases) |
| bSDD Classification | SketchUp 2024+ | In development |

The plugins are developed in a private repository and published here: releases first, source
per plugin as it is prepared for open source. Release tags in this repository point at this
README's history; the source history arrives with the source.

## Installing

Download the installer for your host from the latest
[release](../../releases/latest). The Revit plugins check this repository for new versions and
notify you inside the host.
